SATS FORMAT

ವರ್ಗಾವಣೆ ಪ್ರಮಾಣ ಪತ್ರ (TC) / Transfer Certificate

ಸರ್ಕಾರಿ ನಿಯಮಾವಳಿಗಳ ಪ್ರಕಾರ SATS ನಮೂನೆಯಲ್ಲಿ ವರ್ಗಾವಣೆ ಪ್ರಮಾಣ ಪತ್ರಗಳನ್ನು ಮುದ್ರಿಸಿ. ವಿದ್ಯಾರ್ಥಿಯ ವರ್ಗಾವಣೆ ಸಂಖ್ಯೆ, ಮಾಧ್ಯಮ, ಶಾಲಾ ದಾಖಲಾತಿ ವಿವರಗಳು ಮತ್ತು ಜನ್ಮ ದಿನಾಂಕದ ಅಕ್ಷರಶಃ ಅನುವಾದವನ್ನು ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಸಿದ್ಧಪಡಿಸುತ್ತದೆ.

ಟಿಸಿ ಮುದ್ರಿಸಿ / Print TC
CCE FORMAT

ಅಂಕಪಟ್ಟಿ (Marks Card) / Progress Report

ವಿದ್ಯಾರ್ಥಿಗಳ ಶೈಕ್ಷಣಿಕ (SA1, SA2) ಮತ್ತು ಶೈಕ್ಷಣಿಕೇತರ ಕೌಶಲ್ಯಗಳ ಮೌಲ್ಯಮಾಪನ ಅಂಕಪಟ್ಟಿಗಳನ್ನು ಮುದ್ರಿಸಿ. ಮಾಸಿಕ ಹಾಜರಾತಿ ವರದಿ ಹಾಗೂ ಗರಿಷ್ಠ ಪ್ರಗತಿ ಮೌಲ್ಯಮಾಪನ ವಿವರಗಳನ್ನು ಅಳವಡಿಸಿದೆ.

ಅಂಕಪಟ್ಟಿ ಮುದ್ರಿಸಿ / Print Marks Card
COMING SOON

ಅಧ್ಯಯನ ಪ್ರಮಾಣ ಪತ್ರ / Study Certificate

ವಿದ್ಯಾರ್ಥಿಗಳ ವಿದ್ಯಾರ್ಥಿವೇತನ, ಹೊಸ ಪ್ರವೇಶ ಮತ್ತು ಇತರ ಕಚೇರಿ ಉದ್ದೇಶಗಳಿಗಾಗಿ ಅಧಿಕೃತ ಅಧ್ಯಯನ ಮತ್ತು ನಡತೆ ಪ್ರಮಾಣ ಪತ್ರಗಳನ್ನು ಮುದ್ರಿಸಲು ಸೌಲಭ್ಯ.

COMING SOON

ನಡತೆ ಪ್ರಮಾಣ ಪತ್ರ / Character Certificate

ವಿದ್ಯಾರ್ಥಿ ಶಾಲೆಯಲ್ಲಿದ್ದ ಅವಧಿಯ ನಡತೆ ಮತ್ತು ಶಿಸ್ತನ್ನು ಪ್ರಮಾಣೀಕರಿಸಲು ಉನ್ನತ ಶಿಕ್ಷಣ ಸಂಸ್ಥೆಗಳಿಗೆ ಸಲ್ಲಿಸಲು ನೀಡುವ ನಡತೆ ಪತ್ರ.
